# UI Patterns

> Page/Panel/Popup architecture, Menu system, Layout, French (_FR) suffix pattern.

## Trạng thái: 📝 Chưa có nội dung

### Patterns

| Pattern | Mô tả | Ví dụ |
|---|---|---|
| Page (`*View.aspx`) | Main data display | `TrxView.aspx` |
| Panel (`Panel*.aspx`) | Embedded user control | `PanelClientSearch.aspx` |
| Popup (`Popup*.aspx`) | Modal dialog | `PopupClientAdd.aspx` |
| French (`*_FR.aspx`) | Same code-behind, different markup | `Client_FR.aspx` |
| Print (`*Prn.aspx`) | Print-friendly version | `CommViewPrn.aspx` |

AOT: As of Trade: basically it is a back dated order. For example: Today is April 25 but I order for April 15 trade date.  
The reasons can be many. Most of the time is missing trx. For example client instructed the rep to place order for $5000 of a fund, the rep was playing golf and then forgot, a few days later the client calls and asks where is my trade, now the rep has to place an order with back-dated trade date.  
   
REV: reversal is a cancellation of a valid trade. The trade is already settled and now is being cancelled, this action called reversal as $ already exchange hand, so everything needs to be reversed.  
So reversal always based on and existing trade.  
   
When cancelling a contract trade (not settled yet), then that action is CAX.  
   
CAX, AOT and REV orders “might” result “dilution”.  
   
Dilution is an amount results from price difference between the execution of the trade and the trade date of the trade.  
   
For example:  
On April 15, Joe bought fund “A” 50 units with a price of $10 per unit: so the trx amount is 10 x 50 \= $500  
On April 25, Joe reverses that trx on April 15\.  
Fund “A” price on April 25 is $12 per unit so the difference is $2 per unit so for 50 units, there is an extra $100 when the fund company has to dispose that 50 units. So there is no dilution.  
If Fund A on April 25 has the price of $8 per unit, then there is a shortfall of $100, so the dilution amount \= $100 that the dealer has to pay the fund company.  
   
If there is a original sell, the situation is reversed.
